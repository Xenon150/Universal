# Universal

Копия UniversalSynSaveInstance и зависимостей для сохранения доступной клиенту структуры Roblox-проекта. Используйте только для собственных проектов или при наличии разрешения правообладателя.

## Файлы

- `run.luau` — запуск с настройками из запроса.
- `saveinstance.luau` — исходник сохранения; ссылки на четыре исполняемые зависимости заменены на этот репозиторий.
- `StreamBuffer.luau`, `UniversalMethodFinder.luau` — вспомогательные модули.
- `vendor/Base64.luau`, `vendor/llz4.luau` — дополнительные реализации кодирования и сжатия; их лицензии находятся в `licenses/`.

Основной файл взят из [rbxlx/UniversalSynSaveInstance](https://github.com/rbxlx/UniversalSynSaveInstance) на коммите `edf27045c185d66a952f83f5a18a4cc74a49c0d3`: это доступная полная версия upstream, а не гарантия побайтового совпадения с текстом из сообщения. Лицензия проекта — `LICENSE` (AGPL-3.0). Модули из [rbxlx/SomeHub](https://github.com/rbxlx/SomeHub) взяты с коммита `5707267b4e091f550e67da98a7e050106324770e`; отдельной лицензии в этом репозитории обнаружено не было. Base64 взят из [daily3014/rbx-algorithms](https://github.com/daily3014/rbx-algorithms) (коммит `468dde82bdba89176157dcec90ba503b7046f5b3`), llz4 — из [RiskoZS/llz4](https://github.com/RiskoZS/llz4) (коммит `57d869215b7a061121f5492ecff245989638816a`).

## Запуск

Содержимое `run.luau` загружает `saveinstance.luau` из ветки `main`. Для работы нужны Roblox и совместимая среда, предоставляющая `HttpGet`, `loadstring`, запись файлов и при необходимости декомпилятор и другие дополнительные функции. Это не обычный скрипт Roblox Studio. Запускайте удалённый код только после проверки исходников и доверяя среде выполнения.

В `run.luau` дополнительные настройки закомментированы: уберите `--` перед нужной строкой, чтобы включить её. Для уже присутствующих параметров меняйте значение существующей строки вместо добавления второго ключа. Полная справка и примеры — в [docs/options.md](docs/options.md).

Файл сохраняется в файловой области среды выполнения, **не загружается автоматически на GitHub**. Чтобы положить результат на GitHub, сначала перенесите его оттуда на компьютер, проверьте содержимое и загрузите отдельно. В сохранении могут быть данные игроков и приватные материалы; не публикуйте их без разрешения.

## Ограничения

- `full` не гарантирует сохранение всего: серверные скрипты и данные, не реплицированные клиенту, недоступны; результат декомпиляции зависит от среды. Часть объектов и свойств может быть пропущена или заменена.
- `DecompileTimeout = -1` отключает таймаут и может привести к бесконечному ожиданию; `SafeMode = false` и работа сторонних скриптов повышают риск нестабильности. `NilInstances` требует `getnilinstances`. `IgnoreDefaultProperties` влияет только на XML, не на бинарный формат.
- Исходная настройка `IgnoreSharedStrings` отсутствует в доступной версии USSI: неизвестные настройки игнорируются, поэтому она не включена в `run.luau`.
- Динамические API-дампы Roblox, история версий и данные ассетов по-прежнему запрашиваются с исходных внешних источников: это изменяющиеся данные, а не четыре исполняемые зависимости. При отсутствии доступа часть возможностей может не работать. Если используете другую ветку, обновите URL в `run.luau` и `saveinstance.luau`.
